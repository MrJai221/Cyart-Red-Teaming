# CyArt Red Teaming - Week 2: Advanced Analysis & IR

## 🎯 Overview
This repository contains the documentation and practical artifacts for Week 2, focusing on Theoretical Threat Analysis, Security Frameworks, and a Full Incident Response Cycle.

## 📁 Repository Structure
- **/Theory**: STRIDE modeling, MITRE ATT&CK mapping, and Security Frameworks.
- **/Practical**: Sigma rules, Malware analysis reports, and Vulnerability scans.
- **/Capstone**: Full Incident Response documentation for the VSFTPD exploit.
- **/Screenshots**: Evidence of tool execution and results.

## 🛠️ Tools Used
- **Offensive**: Metasploit, Nmap
- **Defensive**: Wazuh, Suricata, Sigma, Velociraptor
- **Analysis**: REMnux (Strings), OWASP Threat Dragon
- **Management**: DefectDojo, Google Sheets
